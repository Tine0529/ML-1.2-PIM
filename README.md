# KNN จาก NumPy

โปรเจกต์ตัวอย่างการทำงานของ **K-Nearest Neighbors (KNN)** สำหรับจำแนกจุดข้อมูล 2 มิติ โดยเขียนการคำนวณหลักด้วย NumPy และแสดงผลด้วย Matplotlib

## ไฟล์ในโปรเจกต์

- [`KNN.py`](KNN.py) - เวอร์ชันที่แยกการคำนวณ KNN เป็นขั้นตอน เหมาะสำหรับศึกษาและทำความเข้าใจลำดับการทำงาน
- [`KNNshotCal.py`](KNNshotCal.py) - เวอร์ชันย่อการคำนวณ KNN ให้อยู่ใน expression เดียวด้วย Walrus operator (`:=`)

## หลักการทำงาน

ตัวอย่างนี้มีข้อมูลฝึก 2 กลุ่ม:

- Class 0: จุดบริเวณมุมซ้ายล่าง
- Class 1: จุดบริเวณมุมขวาบน

จุดใหม่ที่ต้องการทำนายคือ `[4, 4]` และกำหนดให้พิจารณาเพื่อนบ้านที่ใกล้ที่สุด `k = 3` จุด โดยทำงานตามลำดับดังนี้:

1. คำนวณระยะห่างแบบ Euclidean ระหว่างจุดใหม่กับข้อมูลฝึกทุกจุด
2. เรียงลำดับและเลือกเพื่อนบ้านที่ใกล้ที่สุด `k` จุด
3. ดู label ของเพื่อนบ้านที่เลือก
4. ใช้เสียงข้างมากเป็นผลการทำนาย

ทั้งสองไฟล์ใช้ข้อมูลและวิธีคำนวณเดียวกัน จึงได้ผลการจำแนกเหมือนกัน แต่ `KNN.py` แสดงค่าระยะห่างและ label ของเพื่อนบ้านใน terminal ด้วย

## สิ่งที่แสดงผล

เมื่อรัน `KNN.py` จะพิมพ์ผลการทำนายและ label ของเพื่อนบ้าน เช่น:

```text
ข้อมูลใหม่ [4 4] ถูกทำนายว่าอยู่กลุ่ม: 0
เพื่อนบ้าน 3 ตัวที่ใกล้ที่สุดคือกลุ่ม: [0 0 1]
```

จากนั้นจะแสดงกราฟที่ประกอบด้วย:

- จุดสีน้ำเงินของ Class 0
- จุดสีแดงของ Class 1
- จุดใหม่สีเขียวรูปดาว พร้อม label ที่ทำนายได้
- เส้นประจากจุดใหม่ไปยังเพื่อนบ้าน `k` จุด
- วงกลมที่มีรัศมีเท่ากับระยะห่างของเพื่อนบ้านตัวที่ไกลที่สุด

## การติดตั้ง

แนะนำให้ใช้ Python 3.8 ขึ้นไป และติดตั้งไลบรารีที่ต้องใช้:

```bash
python -m pip install numpy matplotlib
```

## วิธีใช้งาน

รันเวอร์ชันที่อ่านง่าย:

```bash
python KNN.py
```

หรือรันเวอร์ชันย่อ:

```bash
python KNNshotCal.py
```

โปรแกรมจะเปิดหน้าต่างกราฟหลังจากคำนวณเสร็จ หากต้องการทดลองข้อมูลหรือค่า `k` อื่น ให้แก้ตัวแปร `X_test` และ `k` ในไฟล์ที่ต้องการรัน

## ข้อควรรู้

- `k` ควรเป็นจำนวนเต็มบวกและไม่เกินจำนวนข้อมูลฝึก
- ข้อมูลตัวอย่างมีเพียง 2 features เพราะกราฟแสดงผลบนแกน X และ Y
- โค้ดกำหนด Matplotlib backend เป็น `TkAgg` ดังนั้นเครื่องที่รันควรมีสภาพแวดล้อมแบบ GUI และ Tkinter พร้อมใช้งาน
- `KNNshotCal.py` ใช้ Walrus operator (`:=`) จึงต้องใช้ Python 3.8 ขึ้นไป
